# BEST COACH · 最佳教練

一個廣東話、單一 HTML 檔嘅 NBA 教練經理人模擬遊戲。無 build step、無後端 — 開 `index.html` 就玩。

**玩：** https://szejake218218.github.io/best-coach-nba/

## 玩咩

你係 30 支 NBA 球隊其中一隊嘅主教練。排陣、分配 240 分鐘、每週揀戰術、處理傷兵同更衣室、交易同續約，目標係 24 週後殺入季後賽再贏總冠軍。

### 每週流程
1. **賽前準備** — 睇對手 tag（三分大隊／內線怪獸／快攻／鐵桶防守／球星單打），揀防守方案＋進攻重點，畫面即時顯示預測評分
2. **開波** — 一週 3–4 場；半場落後 8 分會停低問你叫唔叫暫停；最後 1 分鐘分差 5 分內出關鍵一擊
3. **結算** — box score、今週診斷（籃板／失誤／三分／後備得分）、球員心情、傷病、連登體育台留言
4. **調整** — 輪換、角色、交易，再模擬下一週

### 核心機制
- **240 分鐘鐵律**：全隊出場時間必須啱啱好 240
- **體力**：🟢 70%+ ／ 🟡 50–69% ／ 🔴 <50%；紅燈仲打 25 分鐘以上有 70% 即場受傷
- **傷病**：輕傷 1–2 週、中度 3–4 週、重傷 5–7 週；可以「帶傷上陣」（能力 −10%、25% 復發）
- **角色期望**：基石 32 分鐘／主力 26／第六人 19／發展中 16，長期唔夠分鐘會影響心情同化學反應
- **化學反應**：位置契合、心情、磨合期、外線空間、星級滿意度加權
- **戰術 counter**：每隊有 1–2 個 tag，揀啱方案可以差 10 分以上；連續用同一招會被對手適應
- **交易**：只喺 Week 12–14 同休賽期開放，全季 10 次；薪酬 125% 匹配 ＋ 帽空間 ＋ 交易特例；92+ 球星非賣品
- **續約**：可以還價，球員唔滿意會走人
- **季後賽**：分岸前 8，Bo7 逐場打，總決賽對另一岸冠軍
- **教練技能**：每季儲 XP，解鎖額外暫停／高級球探／體能教練／心理教練／談判專家

## 資料來源

- 30 隊名單（2026-27 開季）來自 ESPN public roster API
- 球員 OVR 由合約薪酬換算＋年齡曲線＋年輕球星補正，唔係官方 2K rating
- 選秀球員、自由球員後備係程序生成

## 技術

- 單一 `index.html`（HTML + Tailwind CDN + 原生 JS）
- 進度存在 `localStorage`
- 建議用 Chrome / Edge / Safari；手機可用
